# v1.0.8 객실 점검 목록과 메이드 화면 실시간 갱신

#619의 관리자 객실 점검 목록과 #620의 통보·회수·재배정·알림 갱신 신호를 함께 반영하는 릴리스 후보입니다. 기존 예약 자동 백업 및 모바일 푸시 테스트 발송 #622는 이번 변경 범위 밖입니다.

- 기준은 운영 v1.0.7(main db979984)과 dev ec2898a7입니다. 신규 SQL은 155번 20261125134408_assignment_live_updates 한 건입니다. 운영 API 권한·Swagger 및 릴리스 버전을 함께 확인합니다.
- 정확한 후보에 대한 승인 후 릴리스 PR에서 격리 DB 전체 검증 1회를 실행합니다. 실패·취소·입력 변경 시 재승인 전 재실행하지 않습니다.
- 통과 후 운영 이력 154건을 확인하고, 예상과 다르면 중단합니다. 운영 155번 적용은 별도 승인 후 진행합니다. DB 적용 후 API와 Swagger를 반영하고 버전·상태 및 관리자 목록·메이드 권한 분리를 점검합니다.

- API 되돌림은 기존 버전으로 수행할 수 있습니다. DB 되돌림이 필요하면 기존 예약·업무·알림을 보존하는 변경 계획을 별도 검토합니다.
