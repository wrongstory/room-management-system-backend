# v1.0.7 지연 청소 날짜 정합성

10월 8일 퇴실하고 11월 7일 청소로 배정한 객실의 업무 목록, 담당 통보 이력과 완료 전 예상 주급은 11월 7일에 표시한다. 현장 완료 후에는 한국 시간의 실제 완료일을 사용한다. 원 업무일, 감사와 확정 수익 이력은 보존한다. API 응답에는 원 업무일과 예정 청소일을 함께 제공한다.

## 검증과 운영 반영
- #616 개발 통합 10757693, 운영 기준 v1.0.6 main 0cc0c4ff. 신규 마이그레이션은 154번 한 건이다.
- 릴리스 PR에서 승인된 격리 전체 DB 검증을 한 번만 수행한다. 종료 상태와 검증 증거는 PR에 기록한다. 실패·취소 시 재실행 전 다시 승인받는다.
- 성공 후 운영 이력 153건과 신규 SQL을 대조하고 운영 154번 실행 직전에 별도 승인을 받는다. 반영 순서는 DB, API, 읽기 전용 상태·권한·날짜 확인이다. 기존 예약·청소 업무를 실제로 변경하지 않는다.
- API를 이전 버전으로 되돌릴 수 있다. DB 함수 복원은 이전 정의와 권한을 대조한 별도 변경으로 검토하고, 기존 업무 기록은 보존한다.
